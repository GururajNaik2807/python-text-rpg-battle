# Hero vs. Goblin: Text-Based Battle Simulator

A lightweight, turn-based command-line RPG prototype written in Python. This project demonstrates foundational programming concepts such as Object-Oriented Programming (OOP) design, state-managed turn logic, and terminal-based interactive game loops.

## 🎮 Features
* **Turn-Based Combat:** Alternating turn mechanics managed smoothly via state tokens.
* **Action Choices:** Choose between a standard Attack, a high-damage Heavy Attack, or skipping a turn.
* **RNG Mechanics:** The AI Goblin calculates dynamic, randomized damage pools to keep combat unpredictable.
* **Developer Backdoor:** Built-in cheat codes for debugging and quick testing.
